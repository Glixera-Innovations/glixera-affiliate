# Glixera | Affiliate Services

Glixera Affiliate Services is a Discord bot project for managing partnerships and affiliate relationships for **Glixera Innovations**.

## Purpose

The bot is intended to provide one consistent place for Glixera's public relations team to coordinate partnerships with other communities, and other external actors. It should reduce manual administration while keeping decisions traceable and access appropriately restricted.

## Getting started

The runtime, package manager, Discord library, persistence layer, and hosting environment have not yet been selected. Once those decisions are made, this section will document an exact reproducible setup rather than speculative commands.

The expected development flow is:

1. Clone the repository and switch to the default `master` branch.
2. Install the chosen runtime and project dependencies.
3. Copy the committed environment template to a local ignored environment file.
4. Create a separate Discord application or guild configuration for development.
5. Start the bot in development mode and run the automated checks.

## Privacy and data handling

Partnership management may involve Discord user IDs, guild IDs, role IDs, Roblox community information, staff notes, or contact details.
